Privacy policy

R00K Steward · last updated 16 October 2026

Who uses it

R00K Steward is a single-user app. Its only user is its maker, signed in with their own Google accounts. It does not collect data about anyone else as users.

What Google data it uses

  • Gmail: messages, labels and drafts in the owner's own accounts.
  • Google Calendar: events in the owner's own calendars.

It uses this data only to show the owner their inbox and calendar, sort and label mail, write draft replies, and track bills and subscriptions.

Where the data goes

  • The owner's PC: sign-in tokens and any copies of mail stay on the owner's own computer. There is no R00K server or cloud database.
  • Anthropic (Claude): the text of a message is sent to Anthropic's Claude API so it can be sorted and a draft reply written. Nothing else is shared.
  • Nobody else: the data is never sold, never used for ads, and never used to train AI models.

Google's rules

R00K Steward's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

  • Disconnect in Steward's settings, which revokes access at Google and deletes the saved token.
  • Or remove "R00K Steward" at myaccount.google.com/permissions.
